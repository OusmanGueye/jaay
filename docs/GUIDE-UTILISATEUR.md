# Guide utilisateur

## Premier lancement
1. Ouvrez l'application, saisissez le **code d'activation** (une seule fois).
2. Acceptez les autorisations **Bluetooth** et **Caméra**.
3. Allez dans **Réglages** (engrenage) :
   - renseignez le nom, l'adresse, les téléphones, le logo ;
   - choisissez l'imprimante **BluetoothPrint** puis « Imprimer un ticket de test » ;
   - choisissez la couleur de l'application.
4. (Recommandé) Créez votre compte de sauvegarde dans **Sauvegarde en ligne**.

## Ajouter ses produits
Onglet **Produits** → **Nouveau produit** :
- **Nom** (ex. « Riz brisé 50 kg ») — l'icône est suggérée automatiquement, modifiable.
- **Unité** : sac, carton, kg, litre, pièce… L'unité est indicative. Choisissez `kg` ou `litre` pour pouvoir vendre au poids.
- **Rayon** : Céréales, Boissons… (facultatif, pratique quand il y a beaucoup de produits).
- **Prix** détail, demi-gros, gros (au moins un).
- **Stock** : facultatif.

## Faire une vente
1. Onglet **Vente**.
2. Choisissez le niveau de prix : **Détail / Demi-gros / Gros**.
3. Touchez les produits (appui long = saisir une quantité). Pour un produit au kg, l'application demande :
   - une quantité en kg, ou en g (250 g, 500 g),
   - ou **« par montant »** : le client donne 500 F, l'application calcule le poids.
4. Si besoin : **Remise**, ou **Article libre** (crayon).
5. Touchez le client (par défaut **client comptoir**) pour en choisir un ou en créer un.
6. **Encaisser** : indiquez le montant reçu.
   - Client comptoir : paiement complet.
   - Client nommé : vous pouvez laisser un **reste à crédit** ; le ticket contient alors une reconnaissance de dette à signer.
7. Le ticket s'imprime automatiquement (réglable).

## Encaisser une dette
- Depuis la **fiche client** → « Encaisser » : le montant est réparti sur les plus anciennes factures.
- Ou depuis une **facture** → « Payer une tranche ».
- Un reçu est imprimé ; **Relevé** imprime toutes les factures non soldées.

## Retrouver une facture
- Bouton **scanner** : scannez le QR du ticket, ou tapez le numéro (`F-000123` ou `123`).
- Onglet **Factures** : filtres par période, « impayées ».

## Rembourser
Ouvrez la facture → **Rembourser**. La vente est annulée, l'argent rendu enregistré et le stock remis. Un reçu de remboursement s'imprime.

## Tableau de bord et clôture
Onglet **Accueil** : choisissez la période (aujourd'hui, mois, année…). **Clôturer la caisse** imprime le récapitulatif.

## Sauvegarde et nouvel appareil
- Créez un compte (e-mail + mot de passe) puis confirmez l'e-mail reçu.
- La sauvegarde est automatique dès qu'il y a internet.
- Sur un appareil neuf : installez, activez, connectez-vous au même compte → **Restaurer**.

## Problèmes courants
| Problème | Solution |
|---|---|
| Accents illisibles sur le ticket | Réglages → « Supprimer les accents » |
| Texte coupé ou décalé | Réglages → largeur 42 ou 32 caractères |
| Rien ne s'imprime | Vérifier que BluetoothPrint est choisi ; relancer le test |
| Caméra indisponible | Autoriser la caméra (bouton « Ouvrir les réglages »), ou taper le numéro |
| Logo trop grand | Réglages → taille du logo : Petit |
| Sauvegarde en attente | Normal hors connexion ; elle part au retour du réseau |
